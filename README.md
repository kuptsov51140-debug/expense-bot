# Бот учёта расходов (Telegram + Claude)

Пишешь боту «кофе 250» или отправляешь фото чека — ИИ определяет сумму и категорию и записывает в `expenses.csv` (открывается в Excel). По воскресеньям в 20:00 приходит сводка недели.

## Как это работает
1. Node.js-скрипт слушает Telegram (long polling).
2. Текст или фото уходит в Claude с инструкцией вернуть JSON: сумма, категория, описание.
3. Запись добавляется в CSV; команды `/week`, `/month` считают итоги по категориям, `/undo` удаляет последнюю запись.
4. Доступ только у владельца (`ALLOWED_CHAT_ID`), чтобы чужие сообщения не тратили деньги на API.

## Запуск
1. В Telegram у @BotFather: `/newbot` → получить токен.
2. Ключ API: console.anthropic.com → API Keys.
3. Создать рядом с `bot.js` файл `.env` (без `.txt` в конце) с тремя строками:
   ```
   TELEGRAM_BOT_TOKEN=токен_от_BotFather
   OPENAI_API_KEY=ключ_с_platform.openai.com
   ALLOWED_CHAT_ID=
   ```
4. `node bot.js`, написать боту любое сообщение — он ответит твоим chat id. Вписать его в `.env`, перезапустить.

## Идеи развития
- Запись в Google Sheets вместо CSV
- Месячные лимиты по категориям с предупреждением
- Голосовые сообщения (Whisper)
